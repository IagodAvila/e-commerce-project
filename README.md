# 🛍️ Cara - E-commerce Website

Projeto de interface de um e-commerce de roupas desenvolvido para praticar conceitos de **HTML, CSS e JavaScript**, com foco em layout moderno, organização de produtos e responsividade.

## 🚀 Demonstração

🔗 Acesse o projeto online:  
https://iagodavila.github.io/e-commerce-project/

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Flexbox
- CSS Grid

## 📦 Funcionalidades

- Página inicial com destaque de produtos
- Página de loja com listagem de itens
- Página de produto
- Carrinho de compras
- Layout responsivo para diferentes dispositivos
- Navegação entre páginas do e-commerce

## 🎯 Objetivo do projeto

Este projeto foi desenvolvido com o objetivo de:

- Praticar **estruturação de páginas web**
- Melhorar habilidades de **CSS moderno**
- Aplicar **Flexbox e Grid**
- Criar uma interface de **e-commerce realista**
- Aprender boas práticas de organização de código
